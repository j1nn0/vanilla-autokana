Install deps: `pnpm install`
Lint: `pnpm run lint`
Typecheck: `pnpm run typecheck`
Run tests in watch mode: `pnpm run test`
Run coverage once: `pnpm run test:coverage`
Run a single test file: `pnpm exec vitest run __tests__/AutoKana.test.ts`
Build library: `pnpm run build`
Full verification: `pnpm run ci`
Format source files under src only: `pnpm run format`
