TypeScript library package `@j1nn0/vanilla-autokana` for auto-completing furigana while typing in form fields. Public entrypoint is `src/index.ts`, which exports `bind(...)`, `AutoKana`, and `AutoKanaOption`. Core behavior lives in `src/AutoKana.ts`. Published declaration file is `types/autokana.d.ts`, maintained manually. Vite builds library outputs to `dist/autokana.umd.js` and `dist/autokana.es.js`; `dist/` is generated and should not be hand-edited. Tests live in `__tests__/AutoKana.test.ts` and run in jsdom.
