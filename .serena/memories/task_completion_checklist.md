When finishing changes: update `src/index.ts` and/or `src/AutoKana.ts` as needed, manually sync `types/autokana.d.ts` if public API changed, update `__tests__/AutoKana.test.ts` for behavior changes, then run `pnpm run ci`. Tests run in jsdom and often assert internal `AutoKana` fields/methods, so internal behavior refactors can require test updates. Important behavioral constraints: `bind()`/`new AutoKana(...)` accept element IDs with or without `#` or actual `Element`s; missing name element throws; furigana target is optional; `katakana` supports only `false | 'full' | 'half'`; half-width mode normalizes full-width spaces; conversion detection is polling-based via `checkInterval` and focus/blur interval management.
