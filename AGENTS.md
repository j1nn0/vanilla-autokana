# AGENTS.md

## Snapshot

- TypeScript library package: `@j1nn0/vanilla-autokana`.
- Public entrypoint: `src/index.ts` (`bind(...)`, plus `AutoKana` and `AutoKanaOption` exports).
- Core implementation: `src/AutoKana.ts`.
- Published type declarations are maintained in `types/autokana.d.ts`.
- Build output is generated by Vite into `dist/autokana.umd.js` and `dist/autokana.es.js`; do not hand-edit `dist/`.

## Commands

- Dev setup requires `node >=24` and `pnpm >=10`.
- Install: `pnpm install`
- Lint: `pnpm run lint`
- Typecheck: `pnpm run typecheck`
- Test: `pnpm run test`
- Coverage run: `pnpm run test:coverage`
- Build: `pnpm run build`
- Full verification: `pnpm run ci`
- Single test file: `pnpm exec vitest run __tests__/AutoKana.test.ts`
- Format only touches `src/`: `pnpm run format`

## High-Value Constraints

- Keep `src/` as the implementation source of truth and keep `types/autokana.d.ts` in sync manually when the public API changes.
- `tsconfig.json` includes only `src` and `__tests__`, so declaration drift in `types/` will not be caught by `pnpm run typecheck`.
- Tests run in `jsdom` and intentionally reach internal class fields/methods in `AutoKana`; behavior changes often need test updates in `__tests__/AutoKana.test.ts`, not just public API coverage.
- `bind()` / `new AutoKana(...)` accept element IDs with or without `#`, or `Element` instances. Missing `name` input throws.
- `furigana` is optional; do not assume output element presence in implementation changes.
- `katakana` supports exactly `false`, `'full'`, and `'half'`. In `'half'` mode, full-width spaces are normalized to half-width spaces.
- Conversion detection is polling-based (`checkInterval`, default `30`) and tied to focus/blur interval management in `AutoKana`; avoid refactors that change this behavior unless tests are updated deliberately.
- README examples document an important integration quirk: for Vue/React controlled inputs, consumers should read `getFurigana()` instead of relying on direct writes to the target input’s `value`.

## Style Notes

- Repo style is ESM TypeScript with `strict` mode enabled.
- Formatter/linter defaults are from `oxfmt`/`oxlint`: single quotes, semicolons, `printWidth: 100`.
- Follow existing JSDoc style on exported API surface.

## Safe Workflow

1. Change `src/index.ts` and/or `src/AutoKana.ts`.
2. Update `types/autokana.d.ts` if exports or signatures changed.
3. Add or update tests in `__tests__/AutoKana.test.ts` for behavior changes.
4. Run `pnpm run ci` before finishing.
