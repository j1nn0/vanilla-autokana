## Basic Rules

- All user-facing responses must be in Japanese.
- Use MCP `context7` and `serena` proactively.

## Repository Overview

- Single-package TypeScript library: `@j1nn0/vanilla-autokana` (v1.3.0)
- **Source**: `src/index.ts` (entrypoint) + `src/AutoKana.ts` (main logic)
- **Exports**: `bind(...)`, `AutoKana`, `AutoKanaOption`
- **Build output**: `dist/autokana.umd.js`, `dist/autokana.es.js`, `dist/index.d.ts`
- Types are auto-generated by `vite-plugin-dts` during build. Do not edit `dist/` by hand.
- **Tests**: `__tests__/AutoKana.test.ts` (jsdom environment)
- **Storybook**: `stories/AutoKana.stories.ts`

## Important Commands

- Requirements: `node >=24`, `pnpm >=10` (pinned `pnpm@10.33.2`)
- Install: `pnpm install`
- Lint: `pnpm run lint` (oxlint on `src` + `__tests__`)
- Typecheck: `pnpm run typecheck`
- Test: `pnpm run test` (watch mode) / `pnpm run test:coverage` (run + coverage)
- Single test: `pnpm exec vitest run __tests__/AutoKana.test.ts`
- Build: `pnpm run build` (Vite → UMD + ES + d.ts)
- Watch build: `pnpm run watch`
- Full CI: `pnpm run ci` (`lint → typecheck → test:coverage → build`)
- Storybook dev: `pnpm run storybook`
- Format: `pnpm run format` (oxfmt on `src/` only)

## Implementation Gotchas

- `bind()` / `new AutoKana(...)` accept element IDs with or without `#`, or an `Element` instance.
- Throws `Error` when the `name` element cannot be found.
- `furigana` argument is optional. Do not assume an output element always exists.
- `katakana` supports only `false | 'full' | 'half'`. In `'half'` mode, full-width spaces → half-width spaces.
- Conversion detection is polling-based via `checkInterval` (default `30` ms). Changes here are likely to cause behavioral drift.
- For Vue/React controlled inputs, use `getFurigana()` — do not rely on mutating the output input's `value` directly.

## Config Notes

- `tsconfig.json` includes `src`, `__tests__`, `stories`, `.storybook`, and config files.
- `tsconfig.build.json` extends `tsconfig.json` with `rootDir: "src"`, used by `vite-plugin-dts`.
- Coverage thresholds: lines/functions/statements ≥ 70%, branches ≥ 60%.
- Vitest `globals: true` — `describe`, `it`, `expect` are globally available.

## Recommended Workflow

1. Edit `src/` only; treat it as the source of truth.
2. Update tests in `__tests__/AutoKana.test.ts` if behavior changes.
3. Run `pnpm run ci` before finishing.
