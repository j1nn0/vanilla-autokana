## Repository Overview

- Single-package TypeScript library: `@j1nn0/vanilla-autokana` (v1.3.0)
- **Source**: `src/index.ts` (entrypoint) + `src/AutoKana.ts` (main logic)

- **Build output**: `dist/autokana.umd.js`, `dist/autokana.es.js`, `dist/index.d.ts`

## Implementation Gotchas

- `bind()` / `new AutoKana(...)` accept element IDs with or without `#`, or an `HTMLElement` instance.
- Throws `Error` with `AutoKana:` prefix when the `name` element cannot be found. Message includes guidance for SPA users.
- `furigana` argument is optional. Do not assume an output element always exists.
- `katakana` supports only `false | 'full' | 'half'`. In `'half'` mode, full-width spaces → half-width spaces.
- Conversion detection is event-driven via composition events (compositionstart/compositionend/input).
- For Vue/React controlled inputs, use the `onChange` callback option — it is invoked whenever furigana changes, eliminating the need to poll `getFurigana()`.
- When a furigana output element is provided, an `input` event (bubbles: true) is dispatched on it whenever its value changes, enabling framework reactivity detection.
- `reset()` replaces the deprecated `initializeValues()` method. Both work, but prefer `reset()`.
